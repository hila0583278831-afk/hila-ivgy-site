# HILA IVGY — hero

Static HTML/CSS, no build step. Open index.html.

- index.html — the hero: purple gradient background (assets/hero-bg.webp), 8x5 grid of purple leaf-shaped tiles, headline "Websites / that leave / a mark" in Lia Element SemiBold with baselines snapped to the grid rows, and the HILA IVGY logo (assets/logo.png).
- The hero is one SVG with viewBox 2576x1449 inside a 2576:1449 box, so it scales 1:1 with the design at any width.
- assets/fonts/lia-element-semibold.ttf — check you have a web licence before publishing.
