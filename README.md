# HILA IVGY — Website

האתר האישי של הילה איבגי: מיתוג, לוגואים, שפה עיצובית, קופירייטינג ובניית אתרים.

Static site (HTML / CSS / JS), no build step.

- `index.html` — the page
- `css/style.css`, `js/*.js` — styles and scripts (three.js is vendored in `js/vendor/`)
- `assets/` — images, `fonts/` — Fb Atzofen

Run locally: open `index.html` through any static server (needed for ES modules), e.g. `python -m http.server`.
